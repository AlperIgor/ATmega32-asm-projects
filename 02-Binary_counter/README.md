# avr-simulide-binary-counter

Простой и наглядный пример реализации **бинарного счётчика** на ассемблере для микроконтроллеров AVR (на примере ATmega32). Проект демонстрирует работу с портами ввода-вывода общего назначения (GPIO) и эффект последовательного деления частоты.

## 📊 Демонстрация работы в SimulIDE

Каждый последующий пин порта `PORTA` переключается в два раза реже предыдущего, формируя классическую сетку частот деления:

![Симуляция работы счётчика](circuit)

* **PA0:** 2.000 МГц (Младший бит, самая высокая частота)
* **PA1:** 1.000 МГц
* **PA2:** 500.0 кГц
