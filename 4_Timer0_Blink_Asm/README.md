# ATmega32 Timer 0 LED Blinker (AVR Assembly)

Проект представляет собой прошивку для микроконтроллера **ATmega32**, написанную на **чистом ассемблере AVR**. Программа настраивает 8-битный **Таймер 0** в режиме **CTC** (Clear Timer on Compare Match) и использует метод опроса флагов (Polling) для периодического переключения логического уровня на выводе `PB0` (мигание светодиодом).

Данный метод реализации (без использования векторов прерываний) обеспечивает 100% стабильность работы как на реальном железе, так и в симуляторах электроники (например, **SimulIDE** или **Proteus**), исключая зависания ядра виртуального процессора.

---

## 🛠 Технические характеристики

* **Микроконтроллер:** ATmega32
* **Язык программирования:** AVR Assembly (ASM)
* **Среда разработки:** Microchip Studio / Atmel Studio (AVR Assembler2)
* **Используемая периферия:** Таймер 0, Порт B (вывод PB0)
* **Режим таймера:** CTC (Сброс при совпадении с регистром `OCR0`)
* **Предделитель частоты (Prescaler):** /1024
* **Рекомендуемая тактовая частота чипа:** 1 МГц (1 000 000 Гц)
