# ATmega32-asm-projects
Собрание различных проектов и практических работ для микроконтроллера **ATmega32**, написанных на языке **Ассемблер (AVR ASM)**.
## 🛠 Инструменты разработки
* **IDE:** Microchip Studio (Atmel Studio)
* **Симулятор:** SimulIDE / Proteus Design Suite
* **Язык:** AVR Assembler (AVRASM2)

---

## 📂 Структура репозитория

Каждый проект находится в своей отдельной папке и содержит исходный код (`.asm`)
